# 📖 J.A.R.V.I.S. Command Reference

JARVIS supports 40+ natural voice and typed commands across diverse operational categories:

| Category | Example Voice / Typed Phrases | Action Performed |
| :--- | :--- | :--- |
| **AI Intelligence** | `who is Nikola Tesla`, `explain quantum superposition` | Queries Gemini or Knowledge Synthesizer fallback |
| **Hardware** | `cpu status`, `system stats`, `ram`, `battery` | Real-time diagnostic readouts |
| **System** | `take screenshot`, `capture screen` | Saves full screenshot to `Pictures/JARVIS_Screenshots` |
| **System** | `volume up`, `volume down`, `mute`, `unmute` | Adjusts master OS volume |
| **System** | `lock screen`, `lock workstation`, `lock pc` | Secures Windows workstation |
| **Desktop Apps** | `open vscode`, `open code` | Launches Visual Studio Code |
| **Desktop Apps** | `open spotify`, `open whatsapp` | Opens native desktop app or web player |
| **Desktop Apps** | `open terminal`, `open notepad`, `open calculator` | Launches native utility windows |
| **Desktop Apps** | `open explorer`, `open files` | Opens Windows File Explorer |
| **Media** | `play lofi beats on youtube`, `search youtube for [X]` | Launches YouTube media stream |
| **Search** | `search google for [query]`, `google [query]` | Targeted Google search |
| **Web Links** | `open github`, `open chatgpt`, `open stackoverflow` | Opens web platforms |
| **Atmosphere** | `what is the weather`, `current temperature` | Reports hyper-local weather conditions |
| **Intelligence** | `today's news`, `top headlines` | Reads curated RSS news updates aloud |
| **Memory** | `remember that meeting at 4 PM`, `save note [X]` | Stores timestamped note in `data/notes.json` |
| **Memory** | `read notes`, `what did i ask you to remember` | Reads recent memory entries |
| **Memory** | `clear notes`, `delete notes` | Wipes memory vault |
| **Lexicon** | `define serendipity`, `meaning of ephemeral` | Offline dictionary lookup with fuzzy matching |
| **Persona** | `switch to friday`, `switch to jarvis` | Changes assistant voice and gender |
| **Voice** | `mute voice`, `enable voice`, `female voice`, `male voice` | Toggles TTS audio output |
| **Modes** | `text mode`, `voice mode`, `hybrid mode` | Adjusts input modality |
| **Lifecycle** | `exit`, `quit`, `goodbye`, `shutdown`, `sleep` | Reports session duration and powers down |
